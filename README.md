# Monik Studio - Official Showcase & Developer Compliance Portal

Trang web chính thức và cổng thông tin giới thiệu ứng dụng, trò chơi, tiện ích mở rộng của **Monik Studio**, tích hợp đầy đủ mã QR tải nhanh, thông tin chi tiết từ các kho ứng dụng (App Store, Google Play, Chrome Web Store) và các trang tuân thủ chính sách nhà phát triển (Privacy Policy, Terms of Service, User Data Deletion, App Support, Store Compliance, app-ads.txt).

---

## 🌟 Tính năng nổi bật (Key Features)

- **Danh mục ứng dụng đa dạng**:
  - Ứng dụng di động & tiện ích (Lịch Xưa, DocuShelf, LyNote, MonikShorts...)
  - Trò chơi tương tác (KnifeShooter, HexaBound, ChronoDrift...)
  - Tiện ích trình duyệt (MonikShot, TabFlow, ColorZen...)
- **Thông tin chi tiết chuẩn App Store & Google Play**:
  - Đánh giá sao, phiên bản, dung lượng MB, yêu cầu hệ điều hành.
  - Bộ sưu tập ảnh chụp màn hình (screenshots & hero banners thực tế).
  - Điểm nổi bật (Highlights) & danh sách tính năng (Feature Checklist) chi tiết.
- **Mã hóa URL tải ứng dụng thành mã QR**:
  - Tự động sinh mã QR độ nét cao cho từng ứng dụng và từng nền tảng (iOS, Android, Chrome, Web).
  - Hỗ trợ xem nhanh hoặc tải xuống file ảnh PNG QR code để in ấn / quét di động.
- **Hệ thống Font chữ tiếng Việt chuẩn đẹp**:
  - Sử dụng bộ font chữ **Roboto** (hỗ trợ đầy đủ bộ ký tự dấu tiếng Việt, hiển thị mượt mà trên mọi thiết bị và hệ điều hành).
- **Hỗ trợ đa ngôn ngữ**:
  - Chuyển đổi linh hoạt giữa Tiếng Việt và Tiếng Anh (VI / EN).
- **Đầy đủ trang chính sách & tuân thủ Store**:
  - `/privacy-policy` & `privacy-policy.html`
  - `/terms-of-service` & `terms-of-service.html`
  - `/data-deletion` & `data-deletion.html` (form yêu cầu xóa dữ liệu chuẩn GDPR / CCPA)
  - `/support` & `support.html`
  - `/store-compliance` & `store-compliance.html`
  - `app-ads.txt` & `robots.txt`

## 🛠️ Công nghệ sử dụng (Tech Stack)

- **Frontend**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS, Lucide React Icons
- **QR Code**: QRCode SVG & Canvas renderer
- **Fonts**: Google Fonts Roboto (`'Roboto', 'Droid Sans', Arial, sans-serif`)

## 🚀 Hướng dẫn cài đặt & chạy tại máy cục bộ (Local Development)

```bash
# 1. Cài đặt các gói phụ thuộc
npm install

# 2. Khởi chạy dev server
npm run dev

# 3. Mở trình duyệt tại
http://localhost:3000
```

## 📦 Đóng gói sản phẩm (Production Build)

```bash
npm run build
```
